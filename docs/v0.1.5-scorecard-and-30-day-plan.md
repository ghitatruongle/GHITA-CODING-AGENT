## 3. Coverage policy mới (thay gate giả)

### 3.1 Tier model

| Tier             | Packages                                    | Lines floor v0.2.5 | Ghi chú                                  |
| ---------------- | ------------------------------------------- | -----------------: | ---------------------------------------- |
| **T0 Critical**  | `security`, `agents`, `communication`       |       70 / 55 / 50 | Attack surface + orchestration           |
| **T1 Core**      | `ai-engine`, `memory`, `skills`             |       55 / 50 / 45 | Product brain                            |
| **T2 Product**   | `computer-use`, `browser-control`, `shared` |                 40 | Runtime-heavy, mock-friendly paths first |
| **T3 Satellite** | còn lại                                     |                 30 | Không được claim “production hardened”   |

### 3.2 CI rule (thay block 80% mù quáng)

```text
FOR each package:
  if coverage-summary missing -> FAIL
  if lines < package.vitest.threshold -> FAIL
  if package in T0 and lines < tier.floor -> FAIL
REPORT:
  - honest badge (overall weighted or “tiered”)
  - no global 80% claim until T0+T1 all ≥70
```
