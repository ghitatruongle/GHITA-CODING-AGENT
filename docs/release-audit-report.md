## 2. Release pipeline CI hiện có (thuộc RL3)

- `.github/workflows/release.yml` — kích hoạt tag `v*`; jobs: `release-gate` (integrity/typecheck/lint/test/coverage tiers/clippy/build/smoke) → `create-release` (draft) → `build-windows` / `build-linux` / `build-macos` (matrix x86_64+aarch64) / `build-android` / `build-ios` → `generate-updater-json` (latest.json) → `publish-release` (draft→public).
- `.github/workflows/build-desktop.yml` — matrix build artifact (không publish).

## 4. Kết luận

Các gate hiện có **bao phủ đúng yêu cầu RL1** và đủ để chặn v1.1.0: version drift, artifact cấm, single-file installer + checksum, updater manifest theo platform. **Một bug chặn release đã được tìm thấy và sửa** (shim stream/child_process/module/util) — đăng ký tại `docs/code-review-findings.md` (CR-019).
