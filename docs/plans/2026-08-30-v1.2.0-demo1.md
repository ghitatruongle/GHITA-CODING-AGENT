## TRACK 3 — Rust hóa nhỏ gọn (2 module: pagerank + textops-diff)

### Task 3.1 (P3.1): Chọn module + chốt interface

**Đã khảo sát — chốt 2 đơn vị:**
1. **PageRank ranker** (`packages/shared/src/parser/pageRankRanker.ts`) → port vào **`crates/codegraph`** (crate graph sẵn, cùng domain).
2. **Diff/patch compute** (`packages/agents/src/subagent/sync.ts` dùng diff) → crate mới **`crates/textops`** với `diff_lines`.

**Interfaces:**
- Produces (codegraph): `#[napi] pub fn rank_symbols(files: Vec<FileTagsNapi>, damping: f64, max_iterations: u32, tolerance: f64) -> Result<HashMap<String, f64>>` — cùng semantics với `PageRankRanker.rankSymbols`.
- Produces (textops): `#[napi] pub fn diff_lines(old: String, new: String) -> Result<Vec<DiffLineNapi>>` với `DiffLineNapi { kind: String /* "add"|"del"|"eq" */, text: String }`.
- Cả hai export qua `packages/native-bridge` loader (pattern `getNativeCosine`: candidates `../../rust-napi/index.node…`, trả `null` khi thiếu addon).

- [ ] **Step 1: Xác nhận loader pattern** — đọc `packages/native-bridge/src/*` + `packages/memory/src/search.ts` (cách dùng `getNativeCosine`), giữ đúng cách resolve.
- [ ] **Step 2: Thiết kế fixture parity** — `packages/shared/src/parser/pageRankRanker.fixture.json` (5 file × 10 tag, có cả reference lồng nhau + symbol trùng tên) + `packages/agents/tests/diff.fixture.json` (10 cặp old/new). Sinh bằng cách chạy hàm JS hiện tại, ghi output làm GOLDEN.
