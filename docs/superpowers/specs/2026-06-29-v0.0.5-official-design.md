## 1. Scope & Deliverables

### Goal

Ship **0.0.5 official** (drop `-beta` suffix) with:

- **All 44 audit fixes** from `codebase_audit_report.md`. The audit's P1 (4 items: 3.3, 4.1, 3.1, 4.2) and P2 (4 items: 2.7, 1.5, 3.8, 3.2) are addressed first; the remaining 36 are addressed in the same waves. (The "P3 deferred" framing from the audit's recommendations is overridden — including all 44 keeps the codebase aligned.)
- **5 Q3 2026 features** with **full UI integration**:
  - Notification system (`packages/notification`)
  - Monitoring / Sentry-style (`packages/monitoring`)
  - Rate Limiting & Quota (`packages/quotas`)
  - Code Knowledge Graph (`packages/code-graph`)
  - Voice I/O (`packages/voice`)
- **iOS beta build** — verify the work done in `0.0.5` still builds.
- **17 dependencies cleanup + `sideEffects: false`** — preserve from beta.
- **Coverage gate fail-hard** — preserve from beta.

### Out of scope

- Plugin Marketplace (deferred to 0.0.6)
- Storybook, Visual Regression Tests (v0.2.0)
- Native code signing for production, SBOM (v0.3.0)

### Deliverables

1. **Source code**: all fixes + features merged into `release/0.0.5` branch (uncommitted, user reviews)
2. **Tests**: 144 existing + new regression tests (one per audit fix minimum)
3. **Documentation**:
   - `CHANGELOG.md` — new `## [0.0.5] - 2026-07-XX` section
   - `ROADMAP.md` — mark 5/7 Q3 items done
   - `README.md` — version badge, link to release notes
   - `package.json` — version bump `0.0.5` ✅ (already done)
   - `.release-please-manifest.json` — bump `0.0.4` → `0.0.5`
4. **Release artifacts**:
   - `apps/desktop/src-tauri/sidecar/latest.json` — auto-updater manifest
   - Git tag `v0.0.5` (annotated, uncommitted — user creates)
   - GitHub Release notes (auto-generated from CHANGELOG)
5. **CI green**: typecheck, lint, test, coverage, knip, audit, dogfood

## 4. Risk & Rollback Strategy

### Risk register

| #   | Risk                                                       | Impact | Probability | Mitigation                                            |
| --- | ---------------------------------------------------------- | ------ | ----------- | ----------------------------------------------------- |
| R1  | 2.14 DNS Rebinding fix breaks working URLs                 | High   | Medium      | Tests across many domains; loopback fallback          |
| R2  | 3.3 IPC token hurts dev experience                         | Medium | High        | Auto-generate token in Rust, log in dev               |
| R3  | Tauri changes (3.1, 3.2, 3.5, 3.6) break macOS/Linux build | High   | Medium      | 3-OS CI matrix; don't merge on red                    |
| R4  | Code-graph slows down desktop on large workspaces          | High   | High        | Default off; build on user demand; cache              |
| R5  | Voice Web Speech API inconsistent                          | Medium | High        | Feature flag; text-input fallback                     |
| R6  | Big-bang merge conflicts between waves                     | High   | High        | Merge per-wave into `release/0.0.5`; rebase as needed |
| R7  | 2.9 Budget persistence needs schema migration              | Medium | Low         | Versioned JSON; fallback to 0                         |
| R8  | iOS ad-hoc rejected by Apple                               | Low    | Low         | Not submitting to App Store in 0.0.5                  |
| R9  | Users miss marketplace                                     | Low    | Medium      | Clear release notes; roadmap to 0.0.6                 |
| R10 | Coverage gate false positive on new files                  | Medium | Low         | Verify in W3 before tag                               |

### Rollback

- **Intra-wave:** revert single fix; defer to P3 if needed.
- **Inter-wave:** `git revert` wave commits from `release/0.0.5`; fix; re-apply.
- **Post-release:** hotfix branch `hotfix/0.0.5.x` → `v0.0.5.1` patch release.
- **Emergency stop:** if new RCE found, pause, public advisory, ship as `0.0.5.1`.
