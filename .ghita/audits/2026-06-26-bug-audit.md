### C1. Missing Tauri command handler `run_grill_session`

- **File:** `apps/desktop/src/components/DocsGrillerDashboard.tsx:92`
- **Backend:** `apps/desktop/src-tauri/src/lib.rs:556-591`
- **Problem:** Frontend gọi `invoke<GrillSession>('run_grill_session', { docsPath })` nhưng command này **không tồn tại** trong `invoke_handler`. Click "Run" sẽ throw `Tauri: command 'run_grill_session' not found`.
- **Suggested fix:**
  ```rust
  #[tauri::command]
  async fn run_grill_session(docs_path: String) -> Result<GrillSession, String> {
      // implementation
  }
  // then add to invoke_handler![...]
  ```

### C2. Pairing codes + hostnames leaked to public KV endpoint

- **File:** `apps/desktop/src-tauri/sidecar/server.mjs:296-346`
- **Problem:** Khi `GHITA_CLOUD_DISCOVERY=1`, mỗi pairing code 6-char + LAN IP + hostname được POST lên `keyvalue.immanuel.co` với `appKey: 'an6h273b'` hardcoded. Bất kỳ ai cũng có thể enumerate codes (36⁶ ≈ 2.2B keyspace, dễ brute-force với IP filter). Đây thực chất là một dịch vụ discovery pairing code public.
- **Suggested fix:**
  - Xóa hẳn function này, HOẶC
  - Require explicit user opt-in per session, cung cấp API key qua secure channel (không hardcode), HOẶC
  - Default env value = disable, opt-in rõ ràng

## 🔴 HIGH — Fix trước release tiếp theo

### H1. Sidecar Node process bị orphan khi Tauri shutdown

- **File:** `apps/desktop/src-tauri/src/lib.rs:213-249`
- **Problem:** `Child` handle của Node sidecar chỉ rely on `kill_on_drop`; không có explicit `.kill()` khi window đóng. Node process tiếp tục chạy, giữ port, không cleanup.
- **Suggested fix:**
  ```rust
  app.on_window_event(|event| {
      if let WindowEvent::CloseRequested { .. } = event {
          if let Some(child) = CHILD_HANDLE.lock().take() {
              let _ = child.kill();
          }
      }
  });
  ```

### H2. Capability allowlist thiếu `zsh`

- **File:** `apps/desktop/src-tauri/capabilities/default.json`
- **Backend:** `apps/desktop/src-tauri/src/terminal.rs:127-141`
- **Problem:** `terminal::resolve_shell` đã hỗ trợ `zsh` nhưng capability `shell:execute` chưa liệt kê `zsh`. Mọi `invoke('terminal_create', { shell: 'zsh' })` sẽ fail ở capability layer dù Rust đã accept.
- **Suggested fix:**
  ```json
  { "name": "zsh", "cmd": "zsh", "args": true }
  ```

### H3. Iframe sandbox `allow-scripts allow-same-origin` phá vỡ isolation

- **File:** `apps/desktop/src/components/WebViewPanel.tsx:281-310`
- **Problem:** Kết hợp `allow-scripts` + `allow-same-origin` cho iframe proxied pages → trang web có thể đọc/sửa cookies & storage của parent origin nếu navigate within proxied origin. Cross-tab escalation có thể xảy ra.
- **Suggested fix:** Bỏ `allow-same-origin` nếu có thể, hoặc generate unique proxied origin per tab.

### H4. CSP chặn favicon + thiếu `https://www.google.com`

- **File:** `apps/desktop/src-tauri/tauri.conf.json:40`
- **UI:** `apps/desktop/src/components/WebViewPanel.tsx:305`
- **Problem:** `WebViewPanel` load favicon từ `https://www.google.com/s2/favicons` nhưng CSP `img-src` không liệt kê. Favicon fail silently, không có diagnostic.
- **Suggested fix:** Thêm `https://www.google.com/s2/favicons` vào `img-src`, hoặc self-host/proxy favicons.

## 🟡 MEDIUM — Sprint tiếp theo

### M1. Race condition nhỏ trong `start_server`

- **File:** `apps/desktop/src-tauri/src/lib.rs:100-104`
- **Vấn đề:** Mutex guard được release giữa check `s.starting` và assignment `s.starting = true`. Window race nhỏ trên multi-core.
- **Suggested fix:** Giữ lock qua cả check + assignment: `let mut s = state.lock().unwrap(); if s.starting { return ... } s.starting = true;`

### M2. URL không encode trong favicon `<img src>`

- **File:** `apps/desktop/src/components/WebViewPanel.tsx:305`
- **Vấn đề:** `tab.displayUrl` interpolate không qua `encodeURIComponent`. Ký tự đặc biệt làm hỏng query string; attacker có thể redirect favicon request.
- **Suggested fix:** `src={`https://www.google.com/s2/favicons?domain=${encodeURIComponent(tab.displayUrl)}&sz=16`}`

### M3. `get_session_token` errors bị nuốt

- **File:** `apps/desktop/src/utils/sharedSocket.ts:38`
- **Vấn đề:** `.catch(() => '')` → empty string silently propagate → confusing 401-style errors sau đó.
- **Suggested fix:** Surface lỗi qua UI boot error; chỉ fallback empty string khi thực sự offline.

### M4. Empty catch blocks trong mobile hook

- **File:** `apps/mobile/src/screens/remote/useRemoteControl.ts:116, 144, 153`
- **Vấn đề:** `storageService.loadSettings()` errors và `Vibration.vibrate()` failures bị nuốt hoàn toàn. User không biết vì sao vibration không hoạt động.
- **Suggested fix:** `catch (e) { console.warn('[useRemoteControl] settings load failed', e); }`

### M5. Cloud publication không retry/backoff

- **File:** `apps/desktop/src-tauri/sidecar/server.mjs:319-321`
- **Vấn đề:** Nếu `keyvalue.immanuel.co` 5xx hoặc DNS fail, discovery fail silently, không queue/retry/UI feedback.
- **Suggested fix:** Queue + retry on transient errors; alert user nếu cloud discovery enabled but failing.

### M6. `rateLimitCleanupInterval` không clear khi sidecar shutdown

- **File:** `apps/desktop/src-tauri/sidecar/server.mjs:373`
- **Vấn đề:** `setInterval` global, không `clearInterval` khi restart → giữ event loop alive, cản clean shutdown.
- **Suggested fix:** Stash handle, clearInterval trên `SIGTERM`/`SIGINT`/`process.on('exit')`.

### M7. Terminal `unlistenData`/`unlistenExit` race khi unmount

- **File:** `apps/desktop/src/components/Terminal.tsx:172-214`
- **Vấn đề:** Nếu component unmount trước khi async setup hoàn tất, cleanup thấy `undefined`. State được set sau unmount → leak PTY process.
- **Suggested fix:** Add `mountedRef` skip post-await setState; invoke `'terminal_kill'` unconditionally trong cleanup.

### M8. `bundled_node` không verify integrity

- **File:** `apps/desktop/src-tauri/src/lib.rs:188-194`
- **Vấn đề:** `node.exe` cạnh `server.mjs` được auto-execute mà không verify hash/signature. Attacker ghi đè file → arbitrary code.
- **Suggested fix:** Embed SHA256 hash vào binary, verify on load.

### M9. Workflow dependency validation giờ throws at runtime

- **File:** `packages/agents/src/workflow/workflow-advanced.ts:182-194`
- **Vấn đề:** Trước silently skip (`if (depStep) await ...`), giờ throw nếu typo trong `dependsOn`. Saved workflows cũ với typo sẽ crash-on-load.
- **Suggested fix:** Validate at workflow **load** time (trong editor), không phải execution time.

### M10. IPC parse errors bị nuốt

- **File:** `apps/desktop/src-tauri/src/lib.rs:236-248`
- **Vấn đề:** Malformed `__GHITA_IPC__:` lines → silently dropped, không signal frontend rằng messages bị mất.
- **Suggested fix:** Add `else { eprintln!("[sidecar] malformed IPC: {}", payload); }`
