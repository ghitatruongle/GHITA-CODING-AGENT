🔬 Phần 2: Phân Tích Sâu 9 Dự Án AI-Core

Dưới đây là phân tích chuyên sâu từng dự án, tập trung vào kiến trúc, tính năng cốt lõi, và những gì có thể trích xuất cho GHITA CODING AGENT.

2A. Hermes Agent ☤ — Self-Improving Agent (Nous Research)

☤
Hệ Thống Tự Học & Cải Tiến
Hermes là agent duy nhất có closed learning loop — tự tạo skills từ kinh nghiệm, cải tiến skills khi sử dụng, nudge bộ nhớ, tìm kiếm cuộc hội thoại cũ (FTS5 + LLM summarization), và xây dựng user model qua các phiên.

Tính năng cần trích xuất:

  • Skills System: 40+ tools, tự tạo skills từ tác vụ phức tạp, skills tự cải tiến khi sử dụng, tương thích agentskills.io open standard
  • Trajectory Compression: Nén lịch sử hội thoại (trajectory_compressor.py ~67KB) để giữ context hiệu quả — quan trọng cho GHITA khi chat sessions dài
  • Multi-Channel Gateway: Telegram, Discord, Slack, WhatsApp, Signal — tất cả từ một process gateway duy nhất
  • Terminal Backends: 7 loại (local, Docker, SSH, Singularity, Modal, Daytona, Vercel Sandbox) — GHITA có thể mở rộng computer-use sang remote execution
  • Cron Scheduling: Lập lịch tác vụ tự động (daily reports, nightly backups) gửi kết quả qua bất kỳ platform nào
  • Subagent Delegation: Spawn subagents song song, Python scripts gọi tools via RPC — zero-context-cost turns
  • State Management: hermes_state.py (~140KB) quản lý toàn bộ trạng thái agent phức tạp

2B. UI-TARS Desktop / Agent TARS — Multimodal Computer Use (ByteDance)

🖥️
GUI Agent & Vision-Powered Computer Control
TARS là stack multimodal AI agent hoàn chỉnh với 2 sản phẩm: Agent TARS (CLI + Web UI với browser agent) và UI-TARS Desktop (native GUI agent dùng Vision-Language Model). Monorepo TypeScript dùng pnpm workspace + Turborepo.

Tính năng cần trích xuất:

  • GUI Grounding: Visual grounding cho phép AI nhận biết chính xác vị trí UI elements trên screenshot — vượt xa nut.js coordinate-based click
  • Hybrid Browser Agent: Kết hợp GUI Agent (vision) + DOM manipulation — chọn chiến lược tối ưu cho mỗi tác vụ
  • MCP Client Infrastructure: packages/agent-infra/mcp-client — MCP client production-ready, hỗ trợ stdio + SSE transport
  • Browser-Use Package: packages/agent-infra/browser-use — browser automation abstraction layer
  • Event Stream Architecture: Protocol-driven Event Stream cho Context Engineering và Agent UI — rất phù hợp để GHITA render real-time trạng thái agent
  • Search Package: packages/agent-infra/search — web search abstraction
  • Agent TARS Core: multimodal/agent-tars/core — core agent loop, multimodal processing

2C. OpenClaw — AI Assistant Platform

🐾
Plugin-First Architecture & Extension Marketplace
OpenClaw là nền tảng AI assistant với kiến trúc plugin-first — core lean, mở rộng qua plugins (code plugins + bundle-style plugins). Hỗ trợ MCP cả server và client, memory plugin slot, skill registry qua ClawHub. Monorepo TypeScript lớn (~100KB package.json).

Tính năng cần trích xuất:

  • Plugin API: 2 loại plugin — Code plugins (runtime hooks, providers, channels, tools) và Bundle-style plugins (skills, MCP servers, config). Ưu tiên bundle-style cho security boundaries
  • Extension System: extensions/ directory — npm package distribution + local extension loading
  • Memory Plugin Slot: Chỉ 1 memory plugin active tại một thời điểm — clean abstraction cho GHITA AgentMemory
  • Skill Registry (ClawHub): Marketplace cho skills/plugins với vetted publishers, provenance, security review
  • Security Model: Safe defaults without killing capability — strong defaults + explicit knobs cho trusted workflows
  • Multi-Channel Support: Messaging channels (theo VISION.md: companion apps trên macOS, iOS, Android, Windows, Linux)
  • ACPX Protocol: Agent-to-agent communication protocol bổ sung MCP

2D. AutoGPT — Agent Building Platform

🤖
Visual Agent Builder & Deployment Platform
AutoGPT cung cấp platform đầy đủ để build, deploy và manage AI agents liên tục. Có 2 phiên bản: AutoGPT Platform (mới, visual builder) và Classic (agent tự trị gốc). Frontend low-code kéo-thả blocks, marketplace pre-built agents, monitoring & analytics.

Tính năng cần trích xuất:

  • Block-Based Agent Builder: UI kéo-thả blocks (mỗi block = 1 action) để tạo workflow — GHITA có thể tích hợp visual workflow builder
  • Agent Lifecycle: Testing → Production deployment controls — quản lý vòng đời agent
  • Agent Marketplace: Thư viện pre-configured agents — người dùng chọn và chạy ngay
  • Monitoring & Analytics: Dashboard theo dõi performance agents
  • Agent Protocol: Standard protocol (AI Engineer Foundation) cho communication giữa agent, frontend và benchmark
  • Forge Framework: Toolkit build custom agents với boilerplate code sẵn

2E. Claude Code — Agentic Coding Tool (Anthropic)

🔮
Production-Grade Coding Agent với Plugin System
Claude Code là tool coding agentic chính thức từ Anthropic, chạy trong terminal. Hỗ trợ tool execution, git workflows, code explanation. Có hệ thống plugins, slash commands extensible, và Agent SDK (@anthropic-ai/agent-sdk). Đã được tích hợp một phần vào GHITA v0.0.1.

Tính năng mới cần trích xuất (chưa có trong v0.0.1):

  • Plugin Directory: plugins/ — organized plugins với /bug command, extensible plugin system
  • Agent SDK: @anthropic-ai/agent-sdk — composable SDK cho custom agent development
  • Sub-Agent Architecture: Spawn specialized sub-agents cho parallel review, validation
  • IDE Integration: VS Code extension, GitHub tag @claude — cần tích hợp tương tự cho GHITA

2F. OpenClaude — Multi-Provider Coding Agent (Gitlawb)

🌐
Open-Source Claude Code với Multi-Provider & gRPC
Fork mã nguồn mở từ Claude Code, đã được modify lớn để hỗ trợ 15+ providers. Có headless gRPC server, agent routing, web search/fetch (DuckDuckGo + Firecrawl), VS Code extension. Đã tích hợp sâu vào GHITA v0.0.1.

Tính năng bổ sung (chưa tích hợp từ v0.0.1):

  • Firecrawl Integration: Web scraping JS-rendered pages — nâng cấp web_fetch tool
  • Provider Profiles: /provider guided setup + saved profiles — UX tốt hơn cho GHITA ApiManager
  • VS Code Extension: Launch integration + theme support — mẫu cho GHITA IDE plugin

2G. OpenHands — AI-Driven Development (SWE-Bench 77.6%)

🙌
Software Agent SDK & Sandboxed Execution
OpenHands (formerly OpenDevin) đạt 77.6% trên SWE-Bench — top AI coding agent. Cung cấp Software Agent SDK (Python), CLI, Local GUI (React), và Cloud deployment. SDK là composable library chạy local hoặc scale 1000s agents cloud. Sandbox execution đảm bảo an toàn.

Tính năng cần trích xuất:

  • Agent SDK Pattern: Composable agent SDK — define agents in code, run locally hoặc cloud — mẫu cho GHITA Agent SDK
  • Sandbox Execution: Docker containers cho safe code execution — tham khảo cho GHITA computer-use sandbox
  • Local GUI (React): REST API + React SPA — tham khảo kiến trúc frontend
  • Chrome Extension: Browser extension cho quick interaction — ý tưởng cho GHITA
  • Multi-User + RBAC: Cloud features — permissions, collaboration — future GHITA cloud

2H. Open Interpreter — Local Code Execution Engine

●
Natural Language → Code Execution (Multi-Language)
Open Interpreter cho phép LLMs chạy code (Python, JavaScript, Shell) trực tiếp trên máy local. Dùng function-calling model với exec() function nhận language + code. LiteLLM cho multi-provider, streaming output, FastAPI server mode. Có profiles YAML.

Tính năng cần trích xuất:

  • Multi-Language Execution: Python, JavaScript, Shell — mở rộng terminal package của GHITA
  • LiteLLM Integration: Unified LLM provider interface — tham khảo cho GHITA ProviderRegistry
  • Conversation Streaming: Generator-based streaming + FastAPI server — mẫu cho streaming architecture
  • Profile System: YAML profiles cho configuration — extensible settings
  • Safety Confirmation: User approval trước execution — đã có trong GHITA, cần nâng cấp granularity

2J. Khám Phá Mới (Plugins & Workflow Mở Rộng)

⚡
Tính năng nổi bật từ Claude Code Plugins & Open-Interpreter

Trong quá trình đào sâu thêm, chúng ta phát hiện thêm các cơ chế xuất sắc để bổ sung vào GHITA:

  • Behavioral Hooks & Security Checkers (từ claude-code/plugins): Cơ chế chặn và cảnh báo các hành vi không mong muốn hoặc nguy hiểm (như rm -rf, eval(), XSS) trước khi Agent thực thi Tool. (Áp dụng cho Phase 3).

  • Local Interpreter Fallback (từ open-interpreter): Khi không dùng được Sandbox container, agent có thể chạy an toàn code Python/Shell trực tiếp trên máy host thông qua cơ chế interactive stream an toàn. (Áp dụng cho Phase 1/4).

🔷 Phase 2: Skills System Nâng Cao + Trajectory Compression

Tích hợp hệ thống skills tự học từ Hermes Agent và trajectory compression cho context optimization.

1

Skills Auto-Creation Engine

Sau mỗi tác vụ phức tạp thành công, AI tự động phân tích quy trình và tạo skill template mới. User review và approve trước khi lưu. Tham khảo Hermes skills/ directory.

Trajectory Compression

4

Cross-Session Memory Search

FTS5 full-text search trên lịch sử conversations + LLM summarization. Khi user hỏi "lần trước mình làm gì với project X?", AI tìm và tóm tắt từ sessions cũ.

✅ Phase 4: Advanced Agent Capabilities — HOÀN THÀNH

Nâng cao năng lực agent với subagent delegation, cron scheduling, và multi-channel gateway.

1

Subagent Delegation

Thiết kế hệ thống SubagentSpawner hỗ trợ spawn các agent con hoạt động độc lập theo cơ chế chạy song song (Parallel) hoặc tuần tự (Sequential). Mỗi subagent thừa hưởng đầy đủ cấu hình AI engine, custom skills registry và metadata cô lập.

2

Cron & NL Scheduler

Phát triển bộ lập lịch CronScheduler kết hợp cú pháp cron tiêu chuẩn và xử lý ngôn ngữ tự nhiên (NL) thông minh (e.g. "every 5 seconds", "hourly", "daily at 10:00") với cơ chế chạy vòng lặp an toàn và kiểm soát tối đa số lần kích hoạt (max iterations).

3

Multi-Channel Gateway

Xây dựng hệ thống GatewayManager quản lý đồng bộ các kết nối từ bên ngoài bao gồm Telegram, Discord và Slack. Hỗ trợ cơ chế tự động chuyển đổi sang Mock Gateway (Simulation Mode) khi thiếu credentials hợp lệ, đảm bảo hệ thống luôn hoạt động ổn định.

4

Composable SDK v2 & Ralph Loops

Tích hợp nâng cao thư viện SDK GhitAgentClient để cung cấp các API gọi trực tiếp từ code, cho phép quản lý vòng đời subagent và kích hoạt vòng lặp tự sửa lỗi (Ralph Loops) có khả năng tự động thực thi, kiểm thử và khắc phục bug mà không cần user tương tác.

✅ Phase 5: Ecosystem & Integration Platform — HOÀN THÀNH

Đưa GHITA vươn ra khỏi Desktop App đơn thuần: Xây dựng hệ sinh thái, đo lường tự động và kiến trúc đa nền tảng dựa trên AutoGPT và OpenClaude.

1

Visual Workflow Builder

Thiết kế canvas kéo thả các node hành động (Visual Workflow Builder), cho phép biên dịch trực quan thành cấu trúc JSON chạy trực tiếp trên Core Agent Engine. Kế thừa từ ý tưởng Workflow Builder của AutoGPT Platform.

2

Agent Protocol & Automatic Benchmarking

Xây dựng hệ thống REST API chuẩn hóa theo đặc tả Agent Protocol của AI Engineer Foundation. Hỗ trợ tích hợp bộ test suite tự động agbenchmark để kiểm thử hiệu năng, độ chính xác của agent qua các bài toán benchmark tiêu chuẩn.

3

Headless gRPC Engine

Phát triển gRPC server với cơ chế Bidirectional Streaming, cho phép tách rời Core Engine để chạy Headless trên server Linux/Docker container cô lập, trong khi UI client vẫn là app Tauri nhẹ chạy trên Windows kết nối bảo mật.

4

Agent Routing & Cost Optimization

Xây dựng bộ Router thông minh tự động lựa chọn model phù hợp cho từng subagent. Các tác vụ đơn giản (e.g. đọc file, chạy lệnh shell cơ bản) được route sang Gemini Flash/Ollama local; chỉ các task kiến trúc/review/code phức tạp mới dùng Claude 3.5 Sonnet.

5

VS Code Extension Integration

Phát triển VS Code Extension giao tiếp trực tiếp với gRPC/IPC server của GHITA đang chạy. Cho phép lập trình viên gọi lệnh chat, duyệt files, và kích hoạt các tác vụ tự động hóa ngay trong sidebar của IDE.

🔷 Chat UI Integration: Khung Chat Là Trung Tâm Điều Khiển

Mọi tính năng thông minh của Core Agent đều được hiển thị và điều khiển thông qua cửa sổ Chat chính (ChatPanel), mang lại trải nghiệm tương tác liền mạch theo phản hồi từ người dùng.

1

Vision Preview & Mouse Path Annotation

Khi agent sử dụng camera/screenshot để thao tác máy tính, ảnh chụp màn hình preview sẽ hiển thị trực tiếp trong ChatPanel. Hover chuột lên ảnh sẽ kích hoạt overlay hiển thị vòng tròn đỏ chỉ rõ tọa độ (click/type) được phân tích bởi UI-TARS.

2

Interactive Tool Cards with Manual Approval

Các tác vụ hệ thống (chạy terminal, viết file) được render thành các widget/card tương tác trong chat. Cho phép người dùng duyệt qua code diff, chỉnh sửa câu lệnh trực tiếp trong ô chat, và bấm nút "Approve" hoặc "Deny" ngay tại chỗ.

3

Real-time Event Stream Panel

Thay vì hiển thị trạng thái chờ im lặng, ChatPanel tích hợp Event Stream Renderer hiển thị sinh động tiến trình đang chạy của AI (e.g. "🔍 Tìm kiếm file index.css...", "📝 Đang viết file...", "⚙️ Chạy npm test (Lần 2/5)...") kèm hiệu ứng micro-animation.

4

Self-Repair Loop Controller (Ralph Loop)

Khi Agent chạy vòng lặp tự động sửa lỗi (Ralph Loop), một banner trạng thái nổi sẽ khóa tạm thời khung chat, hiển thị số vòng lặp hiện tại (e.g. "Vòng lặp sửa lỗi: 3/10"), thông tin test case thất bại, kèm nút "Stop Loop" để dừng khẩn cấp.

5

Skill Learning Card & Hub Integration

Khi hoàn thành tác vụ phức tạp thành công, AI sẽ tự động đề xuất một card: "💡 Tôi đã phát hiện quy trình mới có thể tạo Skill. Bạn có muốn lưu?". Người dùng có thể chỉnh sửa mô tả, xem file yaml/markdown tương ứng và bấm "Lưu vào Skill Hub".

⚠️ LƯU Ý BẢO MẬT & HIỆU SUẤT
  • Vision API Cost: Screenshot analysis gửi lên multimodal LLM tiêu tốn tokens đáng kể. Cần cache screenshots, chỉ analyze khi thực sự thay đổi, và giới hạn resolution.
  • Plugin Sandbox: Code plugins chạy trong isolated process (worker threads hoặc child process) để tránh crash main app.
  • Gateway Security: Multi-channel gateway phải có authentication (DM pairing) để tránh unauthorized access qua Telegram/Discord.
  • Memory Storage: Cross-session search cần SQLite FTS5 — sẵn có trong Tauri via better-sqlite3 hoặc sql.js.
