Mục 3: Kế Hoạch Tích Hợp - 6 Phase

Mục đích: Lộ trình triển khai chi tiết, bố trí lại thành 6 phase hợp lý. Tổng 60 tính năng cần làm, dự kiến ~17 tuần.
Phân bổ: Phase 1 → 2 (tuần tự). Phase 3 + 4 (song song). Phase 5 (sau cùng). Phase 6 (cross-network, song song Phase 4-5).
Phương án: Giữ engine tự viết, chỉ bổ sung tính năng thiếu từ framework tham khảo.
Lưu ý: Các tính năng đã có (Text Generation, Streaming, Tool Calling, MCP, Memory...) đã được xóa khỏi kế hoạch.

3.2 Lộ Trình Chi Tiết

Phase 1: CORE AI ENGINE (1.5 tuần còn lại) - Nền tảng bắt buộc
Bước 1.1 Structured Output: Thêm generateObject() vào ai-engine, Zod schema validation.
Bước 1.2 Tool Call Repair: Auto-retry khi tool call bị parse sai.
Bước 1.3 Tool Context: Bổ sung context injection cho PermissionManager.
Bước 1.4 Smooth Stream + Token Calc: Chunk detection, token counting chính xác.
Bước 1.5 Reasoning Extraction: Parse chain-of-thought từ model output.
Bước 1.6 Error + Embedding + Middleware: Custom error classes, embed(), middleware pipeline.
Phase 2: PROVIDER & MULTI-MODEL (2.5 tuần còn lại) - Kết nối đa nguồn
Bước 2.1 Model Router: LiteLLM Router, load balancing, fallback, retries, cooldowns, strategies.
Bước 2.2 Multi-Provider Registry: createProviderRegistry(), 100+ providers, unified API.
Bước 2.3 Caching System: In-memory, Redis, Qdrant semantic cache, dual cache.
Bước 2.4 Cost & Budget: Token counting, cost tracking per model, budget limits, spending alerts.
Bước 2.5 Middleware Pipeline: wrapLanguageModel(), wrapProvider(), defaultSettings, extractJSON, extractReasoning.
Bước 2.6 Prompt System: Instructions, prompt types, message Zod schemas, prompt templates, versioning.
Phase 3: ENTERPRISE INFRASTRUCTURE (4.5 tuần còn lại) - Bảo mật & giám sát
Bước 3.1 API Key Auth: API keys, JWT, custom auth, proxy_auth/.
Bước 3.2 Rate Limiting: Per-user, per-key, per-model rate limiting, cooldown management.
Bước 3.3 SSO + Teams: Auth0, Okta, Keycloak, Entra ID, WorkOS. Team/project management.
Bước 3.4 Guardrails: Content filtering, PII (Presidio), LLM-as-judge, custom guardrails.
Bước 3.5 Secret Detection + Audit: 80+ credential patterns, audit logging cho mọi request.
Bước 3.6 Observability: Langfuse, Datadog, Prometheus, OTel + 30+ integrations.
Bước 3.7 Alerting: Slack, email (SendGrid/SMTP/Resend), PagerDuty, hanging request check.
Bước 3.8 Enterprise Hooks: Aporia AI, banned keywords, moderation, LlamaGuard.
Phase 4: MULTI-AGENT & PIPELINE (3 tuần còn lại) - AI thông minh
Bước 4.1 ReAct Agent: Thêm createAgent() vào agents package, structured output, middleware.
Bước 4.2 Agent Middleware: Pre/post model hooks cho AgentManager, HITL, retries.
Bước 4.3 Flow Orchestration: Thêm Flow class vào agents, flow-based task pipeline.
Bước 4.4 Agent Adapters: LangGraph + OpenAI Agents adapters cho AgentManager.
Bước 4.5 RAG Knowledge: Knowledge sources, ingestion vào memory package.
Bước 4.6 Runnable Pipeline: Pipeline system: invoke, batch, stream, transform, retry, fallbacks.
Bước 4.7 Message + Storage: Human/AI/System messages, InMemory/FileSystem storage.
Bước 4.8 Hub + Guardrail: LangChain Hub integration, LLM-based guardrail.
Phase 5: ADVANCED & PLATFORM (3.5 tuần còn lại) - Nâng cao & triển khai
Bước 5.1 Multi-modal: Image gen, speech, transcription, video gen.
Bước 5.2 Workflow: WorkflowAgent, lifecycle hooks.
Bước 5.3 Fine-tuning + Batches: Custom model fine-tuning, batch processing, files API.
Bước 5.4 Real-time API + Evals: WebSocket real-time, LLM evaluation framework.
Bước 5.5 UI Adapters: React/Svelte/Vue/Angular, real-time streaming, agent UI stream.
Bước 5.6 Admin Dashboard: Keys, models, usage, teams, budgets, logs, guardrails.
Bước 5.7 Docker Deploy: Docker, K8s/Helm, Terraform, Prometheus monitoring.
Bước 5.8 Gateway + Search + OCR: API gateway, file management, search, OCR, videos.
Phase 6: CROSS-NETWORK PAIRING (2 tuần) - Kết nối khác mạng qua Render.com
Mục tiêu: Cho phép mobile kết nối với desktop ngay cả khi khác mạng WiFi. Chiến lược hybrid: LAN trước (tối ưu), cloud sau (fallback).
Nền tảng: Render.com Free Tier — không cần thẻ tín dụng, 750 giờ/tháng, WebSocket support.
Bước 6.1 Tạo relay-server package: Tách Socket.IO server từ sidecar thành package riêng (packages/relay-server/), loại bỏ Tauri IPC, AI orchestrator, skills execution.
Bước 6.2 Relay server core: Socket.IO relay — chuyển tiếp tin nhắn giữa mobile ↔ desktop. Giữ: pairing, chat, status, rate limiting, cloud discovery.
Bước 6.3 Render deploy config: render.yaml, package.json, start script. Deploy từ GitHub lên Render.com free tier.
Bước 6.4 Hybrid connection logic: Mobile thử kết nối LAN trước (5s timeout) → nếu thất bại thì fallback sang Render relay. Hiển thị loại kết nối cho user.
Bước 6.5 Self-ping keep-alive: Desktop ping Render relay mỗi 10 phút để giữ server sống (không bị sleep sau 15 phút).
Bước 6.6 Test & verify: Test ghép đôi cùng mạng (LAN), khác mạng (cloud relay), reconnect, mất kết nối, server restart.
Phase 7: LOCAL AGENTIC EXECUTION (2 tuần) - Tác nhân lập trình tự trị hoạt động cục bộ
Mục tiêu: Cho phép GHITA CODING AGENT hoạt động tự trị tương tự Antigravity. Cho phép đọc/ghi tệp tin, tìm kiếm, chạy lệnh terminal cục bộ thông qua Sidecar Server với hệ thống giám sát và phê duyệt quyền bảo mật (Workspace Sandboxing & Command Consent Guard).
Bước 7.1 Workspace Sandboxing (ensureInSandbox): Xây dựng middleware ngăn chặn các hành vi đọc ghi file thoát ra ngoài thư mục dự án được chọn (Directory Traversal Escape Prevention).
Bước 7.2 Workspace CRUD File Tools: Cung cấp các công cụ `list_dir`, `read_file` (hỗ trợ line range), `write_file` (hỗ trợ overwrite guard), và `replace_file_content` (thay thế nội dung không kề nhau).
Bước 7.3 Project-Wide Grep Search: Implement công cụ tìm kiếm từ khóa đệ quy tương tự Ripgrep bằng thuần Node.js (`grep_search`).
Bước 7.4 Local Command Execution: Implement công cụ chạy lệnh terminal cục bộ với timeout 30s mặc định và ngăn chặn các command nguy hiểm (`run_command`).
Bước 7.5 Desktop Sidecar integration: Cấu hình các Socket events `set_workspace`, `get_workspace`, và `agent_run` (khởi chạy vòng lặp ReAct).
Bước 7.6 Real-time Telemetry & Approval Handshake: Truyền phát luồng suy nghĩ (`thoughts`), action logs của agent theo thời gian thực tới UI; tích hợp cơ chế xin phép chạy lệnh terminal (`require_approval`) an toàn.
Bước 7.7 Integration Testing & Verification: Viết bộ test suite tự động kiểm thử toàn bộ sandbox, các tool file/command và mô phỏng vòng lặp ReAct chạy thực tế.
