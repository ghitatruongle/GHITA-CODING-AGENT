GHITA CODING AGENT

AI Desktop Agent - Điều khiển máy tính từ xa qua điện thoại

📋 Tổng quan dự án

GHITA CODING AGENT là ứng dụng desktop AI đa năng với giao diện类似 VS Code, hỗ trợ code ứng dụng với AI, quản lý nhiều AI provider, tạo nhóm agents chuyên biệt, và đặc biệt có thể điều khiển từ xa qua điện thoại Android thông qua WiFi/Bluetooth với hệ thống xác thực 2 chiều an toàn.

✨ Tính năng cốt lõi

💻

Code Editor

Giao diện类似 VS Code với AI-assisted coding, autocomplete, refactor, giải thích code, terminal tích hợp

🔑

API Management

Quản lý API keys cho OpenAI, Anthropic, Google Gemini, Ollama, và các custom providers

⚡

Skill System

Tạo và quản lý kỹ năng cho AI: File Manager, Browser Control, Computer Use, Terminal, Screenshot

👥

Agent Groups

Tạo nhóm agents chuyên biệt: Dev Team, Research Team, Automation Team với các vai trò riêng

📱

Remote Control

Kết nối điện thoại Android qua WiFi (xa) hoặc Bluetooth (gần) để điều khiển desktop từ xa

🔐

Secure Pairing

Hệ thống ghép đôi an toàn với mã xác thực 2 chiều, bảo vệ quyền riêng tư

🖥️

Computer Use

AI điều khiển chuột, bàn phím, quản lý cửa sổ ứng dụng trên máy tính

🌐

Browser Control

AI mở Chrome, điều hướng, lấy thông tin, tự động hóa các tác vụ web

🛠️ Tech Stack đề xuất

Tauri + React (Desktop)

UI framework cho Win/Linux, nhẹ hơn Electron, native performance

React Native (Mobile)

Android app điều khiển từ xa, share code với desktop

TypeScript (Toàn bộ)

1 ngôn ngữ cho cả desktop, mobile và backend

Vercel AI SDK / LangChain.js

Tích hợp 100+ AI providers: OpenAI, Anthropic, Google, Ollama...

Playwright (Browser)

Điều khiển Chrome/Firefox, automation web

nut.js (Computer)

Desktop automation: chuột, bàn phím, screenshot

Socket.io (Communication)

Real-time kết nối giữa desktop và mobile

Ollama (Local AI)

Chạy open-source models local, không cần internet
