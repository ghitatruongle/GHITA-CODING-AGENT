🎯 Mục tiêu tổng quan

Xây dựng ứng dụng GHITA CODING AGENT — một desktop AI agent hoàn chỉnh, tích hợp nhiều dự án open-source để tạo thành một sản phẩm thống nhất. Ứng dụng có thể đưa lên GitHub như một dự án open-source, cho phép cộng đồng đóng góp.

Mục tiêu cuối cùng: Một app desktop (Win/Linux) + mobile (Android), code bằng TypeScript, tích hợp 15+ dự án open-source, sẵn sàng cho production.

📦 Danh sách dự án open-source tích hợp

Các dự án dưới đây sẽ được tải về và tích hợp vào GHITA CODING AGENT. Mỗi dự án phục vụ một vai trò cụ thể trong kiến trúc tổng thể.

🔀 Git Workflow

Branch strategy

main
develop
feature/desktop-ui
feature/ai-engine
feature/skills
feature/agents
feature/mobile
feature/communication
hotfix/*
release/v1.0.0

Quy trình commit

  • Mỗi feature trên branch riêng
  • Commit message theo format: type(scope): description
  • Ví dụ: feat(ai-engine): add OpenAI provider
  • Pull Request trước khi merge vào develop
  • Code review tối thiểu 1 người
  • CI/CD phải pass trước khi merge

✅ Checklist trước khi đẩy lên Git

  • Tạo repository GitHub công khai
  • Viết README.md đầy đủ (mô tả, cài đặt, sử dụng, contributing)
  • Thêm LICENSE (MIT hoặc Apache 2.0)
  • Tạo .gitignore phù hợp
  • Tạo .env.example với các biến môi trường mẫu
  • Đảm bảo không commit secrets (API keys, tokens)
  • Setup GitHub Actions CI/CD
  • Tạo CONTRIBUTING.md hướng dẫn đóng góp
  • Tạo issue templates (bug report, feature request)
  • Tạo PR template
  • Chạy lint và test trước khi push
