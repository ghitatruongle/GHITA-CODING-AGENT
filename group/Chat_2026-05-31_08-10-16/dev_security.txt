5. TAURI SCOPE PERMISSIONS
============================================================

TÌNH TRẠNG: 🔴 QUYỀN QUÁ RỘNG

Phân tích capabilities/default.json:

SHELL PERMISSIONS (NGUY HIỂM):
- shell:allow-execute: cmd, powershell với args: true
  → CHO PHÉP CHẠY BẤT KỲ LỆNH NÀO
  → Đây là LỖ HỔNG NGHIÊM TRỌNG nếu có XSS

FILE SYSTEM PERMISSIONS (QUÁ RỘNG):
- fs:scope cho phép:
  + $HOME/** (toàn bộ user directory)
  + $DESKTOP/**
  + $DOCUMENT/**
  + $DOWNLOAD/**
  + $APPDATA/**
  + $LOCALAPPDATA/**

ĐÁNH GIÁ:
🔴 shell:allow-execute với args: true = COMMAND INJECTION RISK
🔴 fs:scope $HOME/** = có thể đọc/ghi bất kỳ file nào
⚠️ Không có sandbox cho shell commands

ĐỀ XUẤT:
[CRITICAL] Giới hạn shell commands whitelist
[CRITICAL] Thu hẹp fs:scope chỉ cho project directory
[HIGH] Thêm user confirmation cho shell execution
[HIGH] Implement path validation cho file operations
